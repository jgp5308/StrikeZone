# Project Instructions

StrikeZone is a bowling video game. Keep the player experience focused on fun, responsive bowling, clear feedback, and easy-to-understand game rules.

## Development Workflow

- Make focused, reviewable changes.
- Preserve existing user work and project conventions.
- After completing each requested change, stage the relevant files, create a descriptive Git commit, and push it to the configured remote repository.
- If pushing fails because no remote or credentials are configured, report the exact blocker.

## Project Structure and Conventions

- The server entry point is `server.js` in the repository root. Static files are in `public`.
- The front end uses plain HTML, CSS, and JavaScript without frameworks.
- Read keys and passwords from environment variables. Never write secrets in the code, and never commit the `.env` file.
- End each task with a Git commit and push.
